# JANA-AI – AI-Powered Citizen Welfare Assistance Platform

JANA-AI is a web application that helps citizens discover government welfare schemes and scholarships based on their eligibility. The platform provides personalized recommendations, multilingual support, and an AI-powered chatbot for assistance.

## Technologies Used

- Java
- Spring Boot
- React.js
- MySQL
- JWT Authentication
- Gemini API

## Features

- User Registration and Login
- Government Scheme Search
- Scholarship Recommendations
- AI Chatbot Assistance
- Email Notifications
- Multi-language Support (English, Kannada, Hindi)

## Project Modules

### Citizen Module
- User registration and login
- Profile management
- Scheme and scholarship search

### Admin Module
- Add and manage schemes
- Add and manage scholarships
- Send notifications to users

### AI Chatbot
- Answers user queries
- Provides guidance on schemes and scholarships

## Database

- Users
- Schemes
- Scholarships
- Chat History

## Future Enhancements

- Mobile application support
- Voice-based chatbot
- Additional regional languages
- Personalized recommendations using AI
